NOVA DESKBOT V1
================

NAME
----
NOVA = Neural Orchestrated Virtual Assistant

Cute identity behavior:
When asked "What is your name?", "Who are you?", or similar, NOVA should answer with a short cute response such as:

"Hi! I'm NOVA ✨ — your little Neural Orchestrated Virtual Assistant."

ESP32 display example:

      ✨ NOVA ✨
       (◕‿◕)
     "That's me!"

Alternative cute replies:
- "I'm NOVA ✨ Your little desk buddy."
- "NOVA! (◕‿◕) Nice to meet you!"
- "I'm NOVA — tiny screen, big personality ✨"
- "NOVA reporting in! (•‿•)ゞ"

The backend should treat NOVA as the permanent assistant identity.


============================================================
PHASE 1 GOAL
============================================================

Build the software foundation first.

For now, ignore:
- microphone
- speakers
- servo motors
- sensors
- cameras
- other electronics

Only use:
1. Web application
2. Backend server
3. Ollama AI
4. ESP32-C6 with display
5. Database / memory storage

Main goal:

WEB APP
   ↕
BACKEND
   ↕
OLLAMA AI
   ↕
ESP32-C6 DISPLAY

The ESP32 should:
- connect over Wi-Fi
- receive chat messages
- display chats
- display NOVA's face
- display emotions
- show connection/status information
- send device status back to the server

============================================================
MEMORY SYSTEM
============================================================

Do NOT send the entire historical chat to the model every time.

Use two layers:
1. Conversation history
2. Long-term memory

Conversation
    ↓
Store full message
    ↓
Memory extractor
    ↓
Worth remembering?
    ├─ No
    └─ Yes → Memory Database

Example:
User: "My favorite car color is red."

Extracted memory:
{
  "type": "preference",
  "key": "favorite_car_color",
  "value": "red",
  "summary": "User prefers red cars.",
  "importance": 0.80
}

Later:
User: "What color should we make the Camaro?"

Backend searches memories.
Relevant memory: "User prefers red cars."

Model context becomes:
Relevant memories:
- User prefers red cars.

User:
What color should we make the Camaro?

============================================================
KEY DESIGN PRINCIPLE
============================================================

The AI decides WHAT NOVA FEELS.
Example:
emotion = "happy"
face = "happy_02"

The ESP32 decides HOW THAT EMOTION LOOKS.
Example:
happy_02
→ load face graphic
→ animate eyes
→ blink
→ animate mouth

This means AI latency does not control animation frame rate.
NOVA can remain visually alive even when the AI is processing.
